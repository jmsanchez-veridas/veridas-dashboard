How to confirm the cause

Checks in order of likelihood. None can be done from the data: they need access to the website and Google Tag Manager.

  1. Google Tag Manager history. Review the versions published on 26 and 27 October: changes to the GA4 tag, its trigger or its consent settings.
  2. Cookie banner. Check whether the tool or its settings changed on those days. If users who reject cookies are now not measured at all, the drop would be this size.
  3. Incognito test. Open veridas.com with Tag Assistant, accept and reject cookies, and check whether the GA4 tag fires and sends the page view.
  4. Website changes for the merger. Ask the web team what was published that week (merger pages, template, scripts).
